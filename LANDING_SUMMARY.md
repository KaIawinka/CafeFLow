### 4. Функционал

#### Header
- Логотип CaféFlow с градиентом

- Переключатель языков
- CTA кнопка "Запросить демо"
- Sticky positioning (прилипает к верху при скролле)

#### Контактная форма
- 5 полей (имя, телефон, email, заведение, комментарий)
- Валидация обязательных полей
- Loading состояние при отправке

- Hover и focus состояния

#### Анимации

- Pulse анимации для декоративных элементов

## 💡 Рекомендации по использованию

### Для редактирования контента
1. Открыть `src/app/i18n/locales/ru/landing.json`
2. Изменить нужные тексты
3. Сохранить (hot reload автоматический)

### Для изменения дизайна
1. Компоненты в `src/components/landing/`
2. Изменить Tailwind классы
3. Цветовая схема легко меняется через градиенты

### Для добавления секций
1. Создать новый компонент
2. Добавить переводы в `landing.json`
3. Импортировать в `page.tsx`
