# 📧 Email Verification Setup Guide

Руководство по настройке системы верификации email с использованием Resend.

---

## 📋 Обзор

Система email верификации обеспечивает:
- ✅ Подтверждение владения email адресом при регистрации
- 🔐 6-значные коды подтверждения с истечением срока
- 🚫 Защиту от одноразовых email адресов
- 📨 Красивые HTML письма с брендингом
- ⏱ Rate limiting (1 запрос в минуту)
- 🔄 Возможность повторной отправки кода

---

## 🚀 Шаг 1: Создание аккаунта Resend

### 1. Зарегистрируйтесь на Resend

Перейдите на [resend.com](https://resend.com) и создайте аккаунт.

**Бесплатный план включает:**
- 100 писем в день
- 3,000 писем в месяц
- Достаточно для тестирования и небольших проектов

### 2. Получите API ключ

1. Войдите в панель управления Resend
2. Перейдите в раздел "API Keys"
3. Нажмите "Create API Key"
4. Скопируйте ключ (начинается с `re_`)

⚠️ **Важно:** Сохраните ключ в безопасном месте. Он показывается только один раз!

### 3. Настройте домен (Опционально для production)

Для production рекомендуется использовать собственный домен:

1. Перейдите в раздел "Domains"
2. Добавьте ваш домен
3. Добавьте DNS записи (SPF, DKIM, DMARC)
4. Дождитесь верификации домена

Для разработки можно использовать домен `onboarding@resend.dev`.

---

## ⚙️ Шаг 2: Настройка переменных окружения

Обновите файл `.env`:

```bash
# Email (Resend)
RESEND_API_KEY="re_your_actual_api_key_here"
EMAIL_FROM="CaféFlow <noreply@yourdomain.com>"
```

**Для разработки:**
```bash
EMAIL_FROM="CaféFlow <onboarding@resend.dev>"
```

**Для production:**
```bash
EMAIL_FROM="CaféFlow <noreply@cafeflow.app>"
```

## 🧪 Шаг 3: Тестирование

### Development Mode

В режиме разработки (если RESEND_API_KEY не настроен):
- Письма не отправляются
- Код верификации логируется в консоль
- API возвращает код в ответе (только в dev!)

### Тестирование регистрации

1. Запустите приложение:
```bash
npm run dev
```

2. Перейдите на страницу регистрации:
```
http://localhost:3000/register
```

3. Зарегистрируйтесь с реальным email адресом

4. Вы будете перенаправлены на страницу верификации

5. Проверьте email (или логи в dev mode) и введите код

### Тестирование API напрямую

#### Отправка кода:
```bash
curl -X POST http://localhost:3000/api/auth/send-verification \
  -H "Content-Type: application/json" \
  -d '{"userId": "your-user-id"}'
```

#### Проверка кода:
```bash
curl -X POST http://localhost:3000/api/auth/verify-email \
  -H "Content-Type: application/json" \
  -d '{"userId": "your-user-id", "code": "123456"}'
```

## 📊 Структура базы данных

Используется таблица `verification_codes`:

```sql
CREATE TABLE verification_codes (
  id UUID PRIMARY KEY,
  user_id UUID NOT NULL REFERENCES users(id),
  code VARCHAR(10) NOT NULL,
  type VARCHAR(50) NOT NULL, -- 'email_verification', 'password_reset', '2fa_login'
  expires_at TIMESTAMPTZ NOT NULL,
  used_at TIMESTAMPTZ,
  attempts INT DEFAULT 0,
  ip_address INET,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

**Особенности:**
- ⏱ Коды действуют 10 минут
- 🔢 Максимум 5 попыток ввода
- 🔄 Старые неиспользованные коды автоматически удаляются
- 📍 IP адрес клиента сохраняется для аудита

---

## 🔒 Безопасность

### Rate Limiting

**Отправка кодов:**
- Максимум 1 запрос в минуту на пользователя
- HTTP 429 при превышении лимита

**Проверка кодов:**
- Максимум 5 попыток на код
- Код аннулируется после 5 неудачных попыток

### Валидация Email

Система автоматически проверяет:
- ✅ Формат email адреса
- ✅ Одноразовые email (tempmail, guerrillamail, и т.д.)
- ✅ Частые опечатки в популярных доменах (gmial.com → gmail.com)

### Защита от злоупотреблений

- 🚫 Блокировка одноразовых email сервисов
- ⏱ Ограничение частоты запросов
- 📊 Логирование всех попыток
- 🔐 Коды действуют ограниченное время

## 📧 Шаблоны писем

### Письмо верификации

Отправляется при:
- Регистрации нового пользователя
- Запросе повторной отправки кода

Содержит:
- 6-значный код
- Срок действия (10 минут)
- Инструкции по вводу
- Советы по безопасности

### Письмо сброса пароля

Отправляется при:
- Запросе восстановления пароля

Содержит:
- 6-значный код
- Срок действия (10 минут)
- Предупреждение о безопасности

## 🐛 Troubleshooting

### Письма не приходят

**1. Проверьте API ключ:**
```bash
echo $RESEND_API_KEY
```

**2. Проверьте логи:**
```bash
npm run dev
# Смотрите логи в консоли
```

**3. Проверьте спам папку**

Письма могут попасть в спам, если:
- Используется тестовый домен
- Домен не верифицирован
- Не настроены SPF/DKIM записи

**4. Проверьте квоты Resend:**
- Бесплатный план: 100 писем/день
- Проверьте использование в панели Resend

### Код не работает

**1. Проверьте срок действия:**
- Коды действуют только 10 минут
- Запросите новый код

**2. Проверьте количество попыток:**
- Максимум 5 попыток на код
- После 5 попыток запросите новый код

**3. Проверьте формат кода:**
- Должен быть 6 цифр
- Без пробелов и других символов

### Rate Limiting

Если получаете ошибку 429:
- Подождите 60 секунд
- Проверьте, не слишком ли часто запрашиваете коды

## 📈 Мониторинг

### Логи

Все события логируются:

```typescript
// Отправка кода
logger.info('Verification email sent', { userId, email });

// Использование кода
logger.info('Verification code used successfully', { userId, type });

// Ошибки
logger.error('Failed to send email', { error, to });
```

### Метрики для отслеживания

- 📊 Количество отправленных кодов
- ✅ Процент успешных верификаций
- ⏱ Среднее время до верификации
- 🚫 Количество ошибок отправки
- 📧 Популярные email провайдеры

## 🌐 Production Deployment

### Vercel

Добавьте переменные окружения в Vercel:

1. Перейдите в настройки проекта
2. Environment Variables
3. Добавьте:
   - `RESEND_API_KEY`
   - `EMAIL_FROM`

### Docker

Добавьте в `docker-compose.yml`:

```yaml
environment:
  - RESEND_API_KEY=${RESEND_API_KEY}
  - EMAIL_FROM=${EMAIL_FROM}
```

### Рекомендации для production

✅ **Обязательно:**
- Используйте собственный домен
- Настройте SPF/DKIM/DMARC записи
- Включите SSL/TLS
- Мониторинг доставляемости писем

✅ **Рекомендуется:**
- Настройте webhook для отслеживания доставки
- Добавьте резервный email сервис (fallback)
- Логируйте все email события
- Настройте алерты при проблемах с доставкой
