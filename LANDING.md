# CaféFlow Landing Page

Профессиональный landing page для продукта CaféFlow — системы автоматизации кафе и ресторанов.

## 🎨 Дизайн

Лендинг использует современный, профессиональный дизайн с:
- Градиентами amber/orange для акцентов
- Темной и светлой темой
- Анимациями и интерактивными элементами
- Адаптивной версткой для всех устройств
- Плавной прокруткой между секциями

## 📐 Структура страницы

### 1. Hero Section (Главная секция)
- Основной заголовок с value proposition
- Описание продукта
- Call-to-action кнопки
- Статистика (клиенты, заказы, экономия времени, рост выручки)
- Mockup интерфейса приложения

### 2. Problems Section (Проблемы)
- 4 ключевые проблемы владельцев заведений
- Визуальные иконки и описания
- Карточки с hover эффектами

### 3. Features Section (Функции)
- 6 основных функций системы:
  - Онлайн-меню и заказы
  - Бронирование столиков
  - Модуль для кухни
  - Программа лояльности
  - Аналитика и отчёты
  - Админ-панель
- Цветовые градиенты для каждой функции

### 4. Benefits Section (Преимущества)
- 6 преимуществ решения:
  - Быстрый запуск
  - Ваш бренд (white-label)
  - Единая система
  - Поддержка 24/7
  - Регулярные обновления
  - Безопасность

### 5. Audience Section (Целевая аудитория)
- 4 типа заведений:
  - Кафе и кофейни
  - Рестораны
  - Пекарни и кондитерские
  - Заведения с доставкой

### 6. Tech Section (Технологии)
- Технологический стек
- Показатели производительности
- Dark theme секция

### 7. CTA Section (Призыв к действию)
- Яркий градиентный баннер
- Контактная форма с полями:
  - Имя
  - Телефон
  - Email
  - Название заведения
  - Комментарий
- Валидация и UX feedback

### 8. Footer (Подвал)
- Логотип и описание
- Навигация по категориям
- Социальные сети
- Копирайт

## 🌍 Мультиязычность

Лендинг полностью переведён на:
- **Русский** (ru) - основной язык
- **Кыргызский** (kg) - дополнительный язык

Переключатель языка расположен в header'е.

## 🎯 Компоненты

Все секции вынесены в отдельные компоненты для удобной поддержки:

```
src/components/landing/
├── HeroSection.tsx          # Главная секция
├── ProblemsSection.tsx      # Проблемы
├── FeaturesSection.tsx      # Функции
├── BenefitsSection.tsx      # Преимущества
├── AudienceSection.tsx      # Целевая аудитория
├── TechSection.tsx          # Технологии
├── CTASection.tsx           # Призыв к действию
├── ContactForm.tsx          # Контактная форма
└── Footer.tsx               # Подвал
```

## 🎨 Цветовая схема

- **Primary**: Amber 600 → Orange 600 (градиент)
- **Background Light**: White, Zinc 50
- **Background Dark**: Black, Zinc 900
- **Text**: Zinc 900 / White
- **Accents**: По функциям (blue, purple, green, etc.)

## 📝 Редактирование контента

Весь текстовый контент находится в:
```
src/app/i18n/locales/
├── ru/
│   ├── common.json      # Общие переводы (meta, nav)
│   └── landing.json     # Контент лендинга
└── kg/
    ├── common.json
    └── landing.json
```

Для изменения текста просто отредактируйте соответствующий JSON файл.

## 🎨 Кастомизация

### Изменить цветовую схему
1. Отредактируйте градиенты в компонентах
2. Основной градиент: `from-amber-600 to-orange-600`
3. Можно заменить на любые цвета из Tailwind palette

### Добавить новую секцию
1. Создайте компонент в `src/components/landing/`
2. Добавьте переводы в `landing.json`
3. Импортируйте в `src/app/[locale]/page.tsx`

### Изменить порядок секций
Просто измените порядок компонентов в `page.tsx`
