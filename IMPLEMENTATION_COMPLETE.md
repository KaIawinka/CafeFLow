### 2. ✅ Middleware и защита маршрутов

**Файл:** `src/middleware.ts`

**Функционал:**
- Иерархия ролей: guest → customer → employee → kitchen → manager → admin
- Role-based защита маршрутов:
  - `/admin` - только admin
  - `/manager` - manager и выше
  - `/kitchen` - kitchen и выше
  - `/employee` - employee и выше
  - `/profile` - customer и выше
- Проверка `requiresApproval` - редирект на профиль если нужно подтверждение
- Редирект на `/access-denied` при недостаточных правах
- Передача информации о пользователе через headers (x-user-id, x-user-role)

### 3. ✅ API Endpoints

#### Аутентификация

**`/api/auth/login` (POST)**
- Email/пароль авторизация
- Поддержка 2FA через Telegram
- Возврат JWT tokens (access + refresh)
- Role-based редирект

**`/api/auth/register` (POST)**
- Регистрация новых пользователей
- Валидация email и пароля
- Автоматическое создание user_settings
- Роль по умолчанию: `customer`

**`/api/auth/verify-2fa` (POST)**
- Подтверждение кода из Telegram
- Проверка временного sessionId

#### Профиль пользователя

**`/api/user/profile` (GET/PATCH)**
- Получение данных профиля
- Обновление: имя, bio, телефон, язык, часовой пояс
- Возврат связанных данных (avatar, settings, telegram)

**`/api/user/settings` (GET/PATCH)**
- Управление настройками уведомлений
- Настройки приватности
- Настройки внешнего вида (тема, компактный режим)

#### Управление ключами бота (только admin)

**`/api/admin/bot-keys` (GET/POST)**
- Получение списка всех ключей
- Создание нового ключа
- Типы ключей: master, manager, kitchen, staff
- Формат: `CAFEFLOW-XXX-XXXXXXXXXXXX`

**`/api/admin/bot-keys/[keyId]` (GET/PATCH/DELETE)**
- Детали конкретного ключа
- Обновление описания, лимитов, статуса
- Удаление ключа

#### Валидация и активация (для Telegram бота)

**`/api/bot/validate-key` (POST)**
- Проверка валидности ключа
- Проверка срока действия и лимитов
- Проверка на уже активированные аккаунты

**`/api/bot/activate-key` (POST)**
- Привязка пользователя к Telegram
- Создание записи активации
- Инкремент счётчика использований
- Автоматическое включение 2FA

### 4. ✅ Telegram Bot

**Файл:** `src/lib/telegram/handlers.ts`

**Команды:**

- **`/start`** - Приветствие и инструкции
- **`/activate`** - Начало процесса активации
- **`/login`** - Инструкция для входа на сайт
- **`/status`** - Проверка статуса активации
- **`/help`** - Справка по командам

**Процесс активации (3 шага):**

1. **Ввод ключа доступа** → Валидация ключа
2. **Ввод email** → Проверка существования пользователя
3. **Ввод пароля** → Верификация и привязка

**После активации:**
- Telegram привязан к аккаунту
- 2FA автоматически включен
- Сохранён ключ активации

## 🔒 Система безопасности

### JWT Tokens

**Access Token:**
- Срок жизни: 15 минут
- Содержит: userId, email, role, status, requiresApproval

**Refresh Token:**
- Срок жизни: 7 дней
- Используется для обновления access token

### Middleware защита

- Автоматическая проверка токена на всех защищённых маршрутах
- Удаление невалидных cookies
- Редирект на login при отсутствии авторизации

### Хеширование паролей

- Использование bcrypt
- Безопасное хранение в БД

## 🚀 Как использовать

### Для пользователей

1. **Регистрация:** `/register` → заполнить форму → автоматический вход
2. **Вход:** `/login` → email/пароль → (опционально 2FA код)
3. **Профиль:** Нажать на аватар в header → "Профиль"

### Для активации Telegram бота

1. Получить ключ доступа от администратора
2. Открыть бота в Telegram: `@cafeflow_manager_bot`
3. Команда: `/activate`
4. Ввести ключ: `CAFEFLOW-XXX-XXXXXXXXXXXX`
5. Ввести email от аккаунта
6. Ввести пароль
7. ✅ Готово! 2FA включен автоматически

### Для администраторов

**Создание ключа доступа:**

```bash
# Через API
POST /api/admin/bot-keys
{
  "keyType": "manager",
  "description": "Для нового менеджера Ивана",
  "maxUses": 1,
  "expiresInDays": 7
}
```

**Управление ключами:**
- `GET /api/admin/bot-keys` - список всех ключей
- `PATCH /api/admin/bot-keys/[id]` - обновить ключ
- `DELETE /api/admin/bot-keys/[id]` - удалить ключ
